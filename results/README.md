# Results directory

This directory is intentionally committed with only this note. Running

```bash
python run_all.py
```

creates:

- `fake_brisbane_results.json` — complete machine-readable results and software versions;
- `fake_brisbane_summary.csv` — flat summary table;
- `RESULTS.md` — human-readable report.

The repository does not ship invented or pre-filled FakeBrisbane numbers. The results are generated by the pinned environment on the machine that performs the run.
